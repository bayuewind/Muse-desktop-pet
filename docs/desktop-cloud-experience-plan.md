# Muse 桌面体验升级

开始：2026-09-30（Asia/Shanghai）。
工作分支：`codex/desktop-cloud-experience`。
基线：`82d3e7f`，98 项自动测试通过。

## 目标

把 Muse 已有的云端能力变成顺手的桌面体验。保持原生连接、
独立授权、加密凭据、明确发送确认和账号隔离，不复制一套云端智能体。

## 工作清单

- [x] 任务中心：运行记录、循环计划、当前活动、更新时间、断线与过期状态。
- [x] 提醒策略与设置：完成/失败/待处理分类、去重、勿扰、隐私保护；系统实际弹出仍待最终验收。
- [x] 成果抽屉：搜索和类型筛选、复用已有预览/保存，明确近期会话覆盖范围。
- [x] 文件输入实现：官方小附件 inline 合同、文件选择/拖放/图片粘贴、本地预览、
  发送确认、取消和去重。每次最多 4 个、合计 8 MB；尚未对真实账号发送附件验收。
- [x] 截图提问实现：当前显示器、本地裁切与数字区域编辑、加入附件；
  合成像素端到端验证通过，真实屏幕权限与系统捕获仍待最终验收。

- [ ] 会话与目标：验证官方接口，增加可验证的原生功能；未接通项提供真实官网入口。
- [ ] 审批：待处理可见、可达，不默认放行；原生操作必须验证请求合同。
- [ ] 验证：自动测试、离线端到端 UI 验证、真实只读连接、打包与安装包验证。
- [ ] 交付：阶段性 Git 提交、验收记录、已验证范围和剩余限制。

## 不可破坏的边界

- 不读取日常浏览器凭据，不输出令牌、私人网关或私人聊天到日志/仓库。
- 不创建真实云端任务、授权连接器、审批、发送消息或上传用户文件来做自动测试。
  任何必须有云端副作用的验收需专门授权；否则用隔离 fixture 并如实标注。
- 不将未知协议猜测成稳定 API，不通过关闭身份验证、TLS 或 Electron 隔离解决问题。
- 旧账号的异步响应、草稿、媒体和通知不能进入新账号。
- 不自动重发送达不确定的任务，不运行云端回复中的代码。
- 退出本地桌宠不等于停止云端任务。
- 近期运行记录、近期收到的附件不冒充全账号完整历史。
