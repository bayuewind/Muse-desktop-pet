# Muse 桌面体验升级

开始：2026-09-30（Asia/Shanghai）。
工作分支：`codex/desktop-cloud-experience`。
基线：`82d3e7f`，98 项自动测试通过。

## 目标

把 Muse 已有的云端能力变成顺手的桌面体验。保持原生连接、
独立授权、加密凭据、明确发送确认和账号隔离，不复制一套云端智能体。

## 不可破坏的边界

- 不读取日常浏览器凭据，不输出令牌、私人网关或私人聊天到日志/仓库。
- 不创建真实云端任务、授权连接器、审批、发送消息或上传用户文件来做自动测试。
  任何必须有云端副作用的验收需专门授权；否则用隔离 fixture 并如实标注。
- 不将未知协议猜测成稳定 API，不通过关闭身份验证、TLS 或 Electron 隔离解决问题。
- 旧账号的异步响应、草稿、媒体和通知不能进入新账号。
- 不自动重发送达不确定的任务，不运行云端回复中的代码。
- 退出本地桌宠不等于停止云端任务。
- 近期运行记录、近期收到的附件不冒充全账号完整历史。
