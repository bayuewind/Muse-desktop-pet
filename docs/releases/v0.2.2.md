# Muse 桌宠 v0.2.2 · Windows 系统代理修复测试包

基于 0.2.1 诊断包增加原生网络系统代理支持。

- 登录会话验证、令牌申请和后续续期通过系统代理解析结果选择连接方式。
- WebSocket 网关共用相同的代理解析逻辑，覆盖主连接、旁聊、身份重新验证及语音使用的网关实例。
- 支持 HTTP CONNECT、HTTPS 代理和 SOCKS，不写死端口，不修改 Windows 或代理软件设置。
- 系统代理 / PAC 解析使用独立的 Electron 内存会话，不读取日常浏览器 Cookie。
- 代理失败不会回退直连；保持 TLS、VM 分配及 Noise 身份验证。
- 脱敏报告新增 HTTPS / WSS、代理解析阶段、选择路径和请求结果，不包含代理地址或凭据。

## 验证方法

1. 退出旧桌宠，安装 `Muse-Desktop-Pet-0.2.2-win-x64-setup.exe`。
2. 确认代理软件的「系统代理」已开启，然后启动桌宠登录。
3. 若仍失败，在退出桌宠前导出脱敏报告交给维护者。

`route` 为代理只证明已选择代理，需结合后续请求结果判断是否成功。
`direct` 只表示系统代理返回直连，不能用来断言 TUN 没有接管。
需要认证的代理（HTTP 407）暂不支持输入账号密码；不支持的配置会明确失败。

这是未签名的 Windows x64 测试包，无自动更新。实际使用者电脑仍需验收。
本地回环测试覆盖真实 HTTP CONNECT / SOCKS5 传输、HTTPS、原生 WebSocket 网关、
证书拒绝、代理拒绝、取消连接、Cookie 保留、响应上限和禁止直连回退。
