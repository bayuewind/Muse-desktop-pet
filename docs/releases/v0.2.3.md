# Muse 桌宠 v0.2.3 · Windows 头像裁剪修复测试包

## 下载与升级

下载附件 `Muse-Desktop-Pet-0.2.3-win-x64-setup.exe` 安装，自带运行环境，无需 Node.js。
`.sha256` 用于校验；GitHub 自动生成的 Source code 是源码，不是安装包。macOS DMG 暂未提供。
Windows x64 未签名测试版，不要通过关闭系统防护绕过未知发布者提示。

## 相比 v0.1.1

- 新增任务中心、近期成果、目标/灵感、确认后发送文件与裁切截图、桌面提醒设置，以及已有旁聊的会话隔离。
- 原生 HTTPS 和 WebSocket 显式使用系统代理解析结果，支持 HTTP CONNECT / HTTPS / SOCKS；
  不写死端口，代理失败不回退直连。使用者反馈该修改已解决目标电脑登录连接超时。
- 账号菜单及登录错误弹窗可导出脱敏诊断报告，记录失败阶段、固定错误码和代理选择结果；
  不记录 Cookie、Token、聊天内容、账号标识、代理地址或凭据。请在退出桌宠前导出。

## 头像裁剪

- 图片、动画和后备形象放入独立的圆形裁剪层，使用 `overflow`、`clip-path` 和隔离层，避免只依赖视频自身圆角。
- 未读角标和状态按钮保留在裁剪层之外，不裁掉按钮阴影、角标或交互区域。
- 显式指定桌宠窗口透明背景，不全局关闭硬件加速。
- 保留 0.2.2 系统代理支持和脱敏诊断功能。

本地 181 项测试通过；100%、125%、150% 页面缩放下检查静态图片及播放中的合成测试视频，
验证四角透明、中心可见。默认渲染及测试启动参数 `--disable-gpu` 下均通过；
正式启动不添加该参数。此测试不能替代受影响电脑的显卡及视频合成路径验收。

退出旧桌宠后安装 `Muse-Desktop-Pet-0.2.3-win-x64-setup.exe`。无需删除账号数据或修改代理设置。
请重点观察空闲、工作动画及其切换时是否还出现矩形白底。

Windows x64 未签名测试包；没有自动更新。

## 验证与限制

- 181 项自动测试、真实本机代理转发测试、打包内容和打包程序冒烟验证通过。
- 头像修复已通过本地渲染像素检查，受影响的另一台电脑仍需实测，不宣称已验证所有显卡组合。
- 仍只支持已实现身份验证的 standard VM；不绕过 CVM / SNP 校验。
- 实际麦克风转写、真实旁聊与长期运行仍需更多验收，已有测试不等于所有场景保证。
