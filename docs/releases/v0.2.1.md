# Muse 桌宠 v0.2.1 · Windows 登录诊断包

基于本地 0.2.0 代码制作的 Windows x64 未签名测试包。

- 账号菜单和登录错误弹窗增加脱敏诊断报告导出。
- 登录流程记录页面元数据、Cookie 导入、会话验证、VM 分配、令牌、网关、身份验证、ping、清理和加密存储的阶段。
- 自动登录失败与手动检查均保留固定错误码；保留可用的 HTTP 状态、白名单内的 DNS / TLS / 超时信息。
- 报告只保留当前进程最近 150 条事件，不包含凭据、账号标识、网址、路径或聊天内容，不自动上传。
- 不改变身份验证要求，不绕过不支持的 CVM 证明；该版本用于定位故障，不宣称已经修复反馈者的登录问题。

## 使用

先退出旧桌宠，再运行 `Muse-Desktop-Pet-0.2.1-win-x64-setup.exe` 安装新包。
复现登录问题后，从「账号 → 导出脱敏诊断报告…」保存 JSON。
请在退出桌宠前导出，将报告连同[反馈模板](../login-troubleshooting.md)交给维护者。

旧版用户无需主动卸载或删除本机数据。此包未签名，无自动更新。
