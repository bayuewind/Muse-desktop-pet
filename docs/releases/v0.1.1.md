## Windows x64 安装包

下载附件 `Muse-Desktop-Pet-0.1.1-win-x64-setup.exe` 即可安装，自带 Electron / Node 运行环境，无需安装 Node.js 或执行 npm 命令。`.sha256` 文件用于校验安装包；GitHub 自动生成的 Source code 是源码，不是可运行的安装包。

> 此版本是**未签名测试版**，Windows 可能提示未知发布者。请确认下载来自本仓库并核对校验值，不要关闭系统防护。macOS DMG 暂未提供。

### 本次更新

- 增加 Windows EXE 安装向导、安装目录选择、开始菜单入口与卸载支持。
- 安装完成页提供“启动 Muse 桌宠”和“创建桌面快捷方式”两个独立勾选项。
- 程序、安装器、桌面快捷方式和系统托盘统一使用桌宠原有的小人头像，并提供多尺寸图标；不再使用通用 EXE 图标。
- 修复 Windows 专用登录浏览器被隐藏启动的问题，支持 Chrome / Edge 和独立登录资料。
- 登录期间每 2 秒自动检测，验证通过后自动保存授权并连接；保留手动检查入口，防止取消或账号切换后误保存旧会话。
- 修复 Windows 凭据权限误判，使用系统加密保护会话；调整 Windows 快捷键提示。

### 安装与使用

1. 安装前通过桌宠托盘菜单退出旧版本；无需先登出或卸载。
2. 运行 EXE，按向导选择安装目录，在最后一页选择是否启动和创建桌面快捷方式。
3. 首次授权需在专用 Chrome / Edge 窗口自行完成登录。已有有效本机授权时不必重新登录。
4. 点击小人打开会话；Windows 快捷键为 `Ctrl+Shift+M`，发送为 `Ctrl+Enter`。

本机登出、卸载不会停止云端任务。安装包不含开发机的账号凭据、浏览器资料或聊天缓存，也不提供自动更新。

### 验证与限制

- 98 项自动测试通过，包含登录取消/并发保护、图标资源和安装页配置检查。
- 打包内容检查与打包程序冒烟测试通过，覆盖生产依赖、窗口交互、回复/附件卡片、音频模块及 Windows 加密往返。
- Chrome、Edge 独立可见登录窗口已在 Windows 实测；完成页的两个复选框已通过隔离预览检查。
- 目前仅支持已实现验证的 standard VM；CVM / SNP 不会跳过验证。
