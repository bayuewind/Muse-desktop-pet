# Muse 桌宠 · Mac 原型

Electron 悬浮宠物 + 桌宠专用 Chrome 进程 + 本机常驻观察器。不是 Chrome 扩展，不读取你现有 Chrome 的 Cookie，不接入现有标签页。**依赖桌宠自己启动的 Chrome 进程，仍是 Web 运行时方案，不是独立实现的 Noise 客户端。**

采用系统已安装的 `/Applications/Google Chrome.app`。本机测试中 Electron 内嵌登录页返回了 4xx，而专用 Chrome 已能完成跳转并返回 HTTP 200；未伪造 User-Agent、隐瞒自动化标记或放宽网页安全校验。

## 启动

```sh
cd "/Users/bayue/Documents/ChatGPT/muse测试使用/desktop-pet"
npm ci
npm start
```

也可双击 `启动桌宠.command`。

在桌宠专用的 Muse 窗口里自行登录。需要后台运行时请**最小化专用窗口，不要关闭**；关闭窗口会使采集停止并显示未知，菜单栏 `◉` 可以再次打开。拖动桌宠顶部短横线移动，× 隐藏，菜单栏可恢复。退出桌宠用其菜单栏“退出桌宠”，会同时关闭它自己启动的专用 Chrome 进程，不会按进程名批量关闭你的其他 Chrome。

不会自动设置开机启动、阻止电脑睡眠、关闭 Chrome 或向 Muse 发消息。登录、验证码、授权与任何账户安全确认由用户完成。如果服务拒绝内嵌浏览器登录，停止该路线，不绕过安全校验。

## 状态与局限

- 只读监听页面已有的 `agent.status` 事件，并订阅页面的活动状态容器。初次附着读取当前会话的明确状态快照，后续状态更新无需等待下一次网关事件。每 15 秒通过现有加密通道发一次 `connection.ping`，每 2 秒采样。
- **只表示当前订阅会话**，不是已验证的全账号后台任务聚合器。当前会话空闲不能推断全部云端任务结束。
- 初次连接的明确非空状态可显示为“网页状态快照”，不会伪称刚收到实时事件。重连、唤醒、保活失败后，未更新的旧快照仍被禁用，需新活动事件或当前会话状态更新；空值或未知码不解释为空闲。
- 断线、保活失败、采集超时与未知活动码都不显示空闲；电脑睡眠后恢复时废弃旧状态。
- 第一版使用 Muse 公共内置 MP4 / 图片，不同步个人自定义头像。视频为圆形裁切，不声称具有透明通道；下载失败有 CSS 形象回退。
- 已关闭页面后台节流和遮挡节流，但**仍需登录后测试隐藏窗口时的事件持续性**。配置项不等于端到端可靠性证明。
- 官网私有状态字段可能随更新改变，届时应修适配器，而不是猜状态。

### 状态读取修复（2026-09-29）

实际登录环境中，`window.__hatch_store__` 是未使用的空调试容器；直接使用它的会话标识会误过滤真实网关事件。现在沿头像 DOM 对应的 React provider 祖先查找实际活动 store，读取明确的当前会话快照并订阅后续更新；网关事件监听作为并行路径。只提取活动码、计数和匹配布尔值，不输出账号 ID、聊天正文或凭据。私有 React 结构变化仍可能要求适配。

在用户登录会话中已验证：实际 provider 的根会话标识存在、活动根标识匹配，收到 `online` 状态且云端保活成功。此项验证不代替长时间后台同步、多会话和睡眠恢复测试。

## 隐私与隔离

专用 Chrome 登录资料保存在 `~/Library/Application Support/MuseDesktopPet/ChromeLogin/`，与日常浏览器分离。保留 Chrome 正常系统钥匙串 / 密码保护机制，不使用 Puppeteer 的 mock keychain / basic password store 默认参数。不导出到代码目录，不输出 Cookie / 令牌 / 聊天内容。不要分享该目录。

远程页面在正常 Chrome 的沙箱里运行，没有 Node、preload 或桌宠 IPC；本地桌宠页面启用 sandbox / contextIsolation，只有“打开窗口 / 隐藏 / 读取脱敏状态”的有限桥接。保留 TLS、同源、钓鱼防护及 iframe 隔离机制。相机等网站权限仍由浏览器提示、用户决定，程序不会自动批准。桌宠通过私有管道控制自己的 Chrome，不开放远程调试 TCP 端口。桌宠代码没有外发遥测或第三方状态存储；Muse / Chrome 自身的网络行为受其各自政策管理。

## 测试

```sh
npm test
npm run smoke
```

单元测试使用模拟网关，smoke 只检查本地窗口渲染和隔离配置，不加载登录页面，不验证真实账号状态。真实联调需用户登录后完成：活动开始 / 结束、最小化专用登录窗、日常 Chrome 退出、专用 Chrome 关闭时正确显示未知、断网重连、电脑睡眠恢复、审批和跨会话范围。

原 SSH 中继项目未更改，也不会使用其中的 `/health` 来推断 Muse 是否工作。
