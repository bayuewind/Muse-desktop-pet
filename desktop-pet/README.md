# Muse 桌宠 · Mac 原生状态版

> 已完成当前账号的原生授权、会话续期、Noise 握手与状态订阅联调。存在本机加密会话时，默认使用原生模式，不启动 Chrome。下方“旧版兼容模式”仅保留为显式可选路径。

## 当前原生模式

- 由 Electron 显示悬浮界面，**Muse 状态来自 Node 直接连接官方网关**，不是来自网页、截图或 React。
- 一次性配对导入桌宠专用的 Muse 会话；凭据由系统钥匙串保护的密钥加密，保存到 `~/Library/Application Support/MuseDesktopPet/native-session.enc`，权限 0600，不进入 Git。
- 原生 HTTPS 续期 / 获取令牌，Noise XX 加密连接；订阅聊天、活动、定时任务，15 秒保活，10 秒补查最近 100 条运行记录和子任务，10 分钟更新会话。
- 标准 VM 重启导致握手公钥轮换时，必须重新验证官方分配的同一 VM、获取新令牌，并用另一条新连接验证候选公钥、新随机挑战及应用保活，全部通过后才更新记录。不同 VM 或不支持的 CVM 证明仍停止，绝不降级验证。
- 界面显示“原生”；按钮“重新连接”只重连原生接口，不打开浏览器。
- “当前未见运行任务”覆盖主会话、子任务查询和最近运行记录，**不是无限历史的全局证明**。已观察到的运行任务若从截断列表消失，不会据此认定完成。
- 断线、身份或授权异常、缺失新快照均明确显示未知 / 待同步；Mac 真正睡眠时本机也会暂停，唤醒后重新同步。

```sh

```

`npm start` 和双击 `启动桌宠.command` 默认使用原生模式。没有本机授权时显示“尚未登录”，不会自动回退到浏览器监听。退出应用请用桌宠菜单栏“退出桌宠”（不是登出账号）。

## 登录、登出与切换账号

**点击小人 → 账号气泡**、会话窗口右上角 **账号 ▾** 或菜单栏 **◉ → 账号** 可管理登录。小人展开菜单仅包含一个账号入口和三个禁用的预留空位；再次点击小人或按 Esc 收起。原有状态卡片、会话 UI 保持不变，**⌘⇧M** 仍打开会话：

1. **登录 Muse…**：确认后打开全新的专用 Chrome 登录窗口，不复用旧账号或读取日常 Chrome。用户自行完成密码、验证码等登录步骤。
2. 登录进入 Muse 聊天后，点击账号菜单的 **登录完成，连接此账号**。程序校验官方 VM 分配、Noise 身份绑定和保活；全部成功后才加密保存新会话，关闭专用窗口并回到原生连接。目前仍仅支持已实现验证的 standard VM，CVM 不会跳过验证。
3. **切换账号…**：确认清除旧账号后，重新执行上述登录。新登录取消或失败时保持未登录，不悄悄恢复旧账号。
4. **登出当前账号…**：确认后断开本机连接、停止录音，清除本机加密授权、旧专用 ChromeLogin 资料、聊天和附件内存缓存、未发送草稿。不会删除已另存的附件，也不会登出日常 Chrome。

登出仅影响本机桌宠，**不会停止 Muse 云端循环任务、删除云端聊天或撤销服务器上的所有会话**。清理失败时锁定为待清理状态，重启也不恢复旧连接，可从账号菜单重试。登录临时目录由桌宠创建并在正常完成/取消时清理；进程异常退出可能留下临时目录，但新登录不会复用它。未登录状态不会自动弹出浏览器。日常运行与续期依然不依赖 Chrome。

账号切换已通过模拟生命周期与安全边界测试；未为测试而登出用户当前账号，第二个真实账号的登录仍需用户操作验收。

## 快速下达任务：文字与语音

- 按 **⌘⇧M** 或菜单栏“下达任务”打开输入框；再次按快捷键或 Esc 收起，草稿保留在本次进程内。点击小人现在展开账号气泡菜单。
- 输入文字后，点击“发送任务”或按 **⌘Enter**；Enter 只换行，中文输入法组词期间不会误发送。目标是 Muse 主会话。
- 点击“语音输入”才会请求麦克风；开发版的系统权限名称可能显示为 **Electron**。
- 再点“停止并转写”：通过独立的原生 Noise 通道将 24 kHz PCM 交给 Muse 的语音接口，结果先放回文本框。**检查、编辑并点击发送后，才下达任务。**
- 最长录音 60 秒；取消、收起、最小化或录音中切换窗口会停止录音。转写音频和草稿不写入磁盘；Muse 服务端的数据处理受其隐私政策管理。
- 发送只在服务器返回消息编号后显示“已确认收到”。断线或超时无法判断是否送达时保留草稿、提示不确定，**不自动重发**；请先到 Muse 检查。
- 快捷键注册失败时，输入框提示占用，仍可用菜单栏“下达任务”入口。

已真实发送一次用户授权的限定测试，服务器确认接收并返回文字与多种附件。实际麦克风录入 / 语音转写尚未实测；语音输入是录音转文字，不是持续监听或实时语音通话。

## 接收回复与附件

- 按 **⌘⇧M** 打开“Muse 会话”，上方接收主会话的实时文字与附件，下方继续输入任务；小人显示本次运行的未读回复数。
- 通过原生加密通道接收聊天事件、按需读取附件，**不依赖 Chrome 标签页**。重连或点击“同步近期回复”读取最近 20 条聊天事件（不是完整历史）。Mac 真正睡眠期间无法实时显示，唤醒后补同步。
- 文字直接显示；代码块可复制，代码文件可按纯文本预览或保存，**不执行代码、不渲染 HTML/SVG**。
- PNG/JPEG/GIF/WebP 图片点“查看图片”才加载；WAV/MP3/M4A/OGG/Opus 音频点“加载音频”后用播放器播放，**不自动播放**，具体解码取决于本机 Electron 支持。
- 其他文件显示附件卡片，只能手动保存；保存使用系统对话框，不覆盖已有文件，不自动打开。仅接受 Muse 工作区的附件路径，不抓取任意外链。
- 单附件上限 16 MiB，代码预览上限 512 KiB；超限或不支持的内容请在 Muse 中查看。本地最多保留 60 条消息，每条最多 30 个附件，正文上限 128 KiB。
- 回复与预览缓存在进程内存中，不自动落盘；仅用户点击保存时写入所选路径。普通日志不记录聊天正文或凭据。

2026-09-29 已通过真实原生通道接收中文文字、Python 代码块、`hello_muse.py`（20 字节）、`green_dot.png`（279 字节）、`beep.wav`（26504 字节），并成功读取三种附件。音频测试是合成提示音，不包含录音或语音识别测试。该机制基于当前 Muse 私有协议，服务更新可能需要适配；并非完整 Muse 网页替代品。

## 旧版兼容模式（显式选择）

`npm start -- --browser` 才会在已授权环境下使用以下旧实现；原生失败不会自动回退到它。

Electron 悬浮宠物 + 桌宠专用 Chrome 进程 + 本机常驻观察器。不是 Chrome 扩展，不读取你现有 Chrome 的 Cookie，不接入现有标签页。**依赖桌宠自己启动的 Chrome 进程，仍是 Web 运行时方案，不是独立实现的 Noise 客户端。**

采用系统已安装的 `/Applications/Google Chrome.app`。本机测试中 Electron 内嵌登录页返回了 4xx，而专用 Chrome 已能完成跳转并返回 HTTP 200；未伪造 User-Agent、隐瞒自动化标记或放宽网页安全校验。

### 旧版状态与局限

- 只读监听页面已有的 `agent.status` 事件，并订阅页面的活动状态容器。初次附着读取当前会话的明确状态快照，后续状态更新无需等待下一次网关事件。每 15 秒通过现有加密通道发一次 `connection.ping`，每 2 秒采样。
- **只表示当前订阅会话**，不是已验证的全账号后台任务聚合器。当前会话空闲不能推断全部云端任务结束。
- 初次连接的明确非空状态可显示为“网页状态快照”，不会伪称刚收到实时事件。重连、唤醒、保活失败后，未更新的旧快照仍被禁用，需新活动事件或当前会话状态更新；空值或未知码不解释为空闲。
- 断线、保活失败、采集超时与未知活动码都不显示空闲；电脑睡眠后恢复时废弃旧状态。
- 第一版使用 Muse 公共内置 MP4 / 图片，不同步个人自定义头像。视频为圆形裁切，不声称具有透明通道；下载失败有 CSS 形象回退。
- 已关闭页面后台节流和遮挡节流，但**仍需登录后测试隐藏窗口时的事件持续性**。配置项不等于端到端可靠性证明。
- 官网私有状态字段可能随更新改变，届时应修适配器，而不是猜状态。

### 状态读取修复（2026-09-29）

实际登录环境中，`window.__hatch_store__` 是未使用的空调试容器；直接使用它的会话标识会误过滤真实网关事件。现在沿头像 DOM 对应的 React provider 祖先查找实际活动 store，读取明确的当前会话快照并订阅后续更新；网关事件监听作为并行路径。只提取活动码、计数和匹配布尔值，不输出账号 ID、聊天正文或凭据。私有 React 结构变化仍可能要求适配。

在用户登录会话中已验证：实际 provider 的根会话标识存在、活动根标识匹配，收到 `online` 状态且云端保活成功。此项验证不代替长时间后台同步、多会话和睡眠恢复测试。

### 旧版隐私与隔离

专用 Chrome 登录资料保存在 `~/Library/Application Support/MuseDesktopPet/ChromeLogin/`，与日常浏览器分离。保留 Chrome 正常系统钥匙串 / 密码保护机制，不使用 Puppeteer 的 mock keychain / basic password store 默认参数。不导出到代码目录，不输出 Cookie / 令牌 / 聊天内容。不要分享该目录。

远程页面在正常 Chrome 的沙箱里运行，没有 Node、preload 或桌宠 IPC；本地桌宠页面启用 sandbox / contextIsolation，只有“打开窗口 / 隐藏 / 读取脱敏状态”的有限桥接。保留 TLS、同源、钓鱼防护及 iframe 隔离机制。相机等网站权限仍由浏览器提示、用户决定，程序不会自动批准。桌宠通过私有管道控制自己的 Chrome，不开放远程调试 TCP 端口。桌宠代码没有外发遥测或第三方状态存储；Muse / Chrome 自身的网络行为受其各自政策管理。
