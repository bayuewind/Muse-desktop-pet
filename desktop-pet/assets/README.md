# Muse icon assets

`muse-avatar.jpg` is the unchanged public avatar already referenced by this
project's desktop pet: https://muse.ai/avatars/hatch.jpg (retrieved 2026-09-29).
The artwork belongs to its original rights holder; this file does not grant a
separate artwork license.

`muse.png` and `muse.ico` are size/format conversions of that same image for the
window, executable, installer, shortcuts and system tray. No AI redraw or crop.
Regenerate locally with `npm run icons` (requires the project's Electron).
